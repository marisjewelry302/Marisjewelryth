# Docs Structure

This folder is for project documentation and archived references only.

## Folders

- `guides/`: active workflow notes and how-to documents used during local development
- `reports/structure/`: generated project tree snapshots and structure reports
- `superpowers/specs/`: approved design specs from agent workflows
- `superpowers/plans/`: generated implementation plans; usually ignored for new files
- `archive/backups/`: manual backup files kept only for reference

## Current documents

- `2026-06-17-static-homepage-routing-worklog.md`: historical worklog for the static-to-React routing migration
- `guides/LOCAL_ARTIFACTS.md`: local artifact storage, preview helpers, and browser test workflow
- `google-sheet-catalogue.md`: historical Google Sheet mapping and manual checker reference
- `reports/structure/tree_WEBSITE.txt`: generated full project tree snapshot
- `reports/structure/public-tree.txt`: generated public folder tree snapshot placeholder
- `supabase-admin-database.md`: protected admin database schema, migration, env setup, and live table-status checks

## Keep this folder light

- Do not store generated screenshots here
- Do not store browser runtime data here
- Do not store temp preview output here
