# Maris Jewelry Static Homepage Routing Worklog

Date: 2026-06-17
Project root: `C:\Users\smakj\OneDrive\เดสก์ท็อป\Marisjewelryth`
Production URL: `https://marisjewelryth.vercel.app/`

## Goal

Keep the existing static storefront architecture, but make the production root URL stay at:

```text
https://marisjewelryth.vercel.app/
```

instead of redirecting to:

```text
https://marisjewelryth.vercel.app/index.html
```

The storefront still uses the legacy static source files:

```text
index.html
pages/*.html
assets/*
```

Those files are synced into `public/` by `scripts/sync-legacy-public.mjs` before `npm run dev` and `npm run build`.

## Root Cause

The previous root route was `app/page.js`:

```js
import { redirect } from "next/navigation";

export default function HomePage() {
  redirect("/index.html");
}
```

That made the browser change the visible URL from `/` to `/index.html`.

## Fix

Deleted:

```text
app/page.js
```

Added:

```text
app/route.js
```

Current behavior:

```text
/ -> serves root index.html directly
```

without changing the browser URL.

The new route handler reads the source static homepage:

```js
readFile(path.join(process.cwd(), "index.html"), "utf8")
```

and returns it with:

```text
Content-Type: text/html; charset=utf-8
```

## Static Product Link Fixes

Admin preview links were changed from relative product links to absolute static product paths:

```text
/pages/product.html?collection=...&id=...
```

This prevents preview links opened from `/admin` from resolving to the wrong path.

Homepage atelier product links now prefer code fields before slug fields:

```js
product.code || product.productCode || product.sku || product.slug || title
```

and generate:

```text
pages/product.html?collection=...&id=...
```
