Response

Success state

Returns request id/status only. No Supabase keys, no internal customer metadata, no order checkout behavior.

Failure

Helpful error

If DB or email env is missing, show a submit error and keep the filled form intact.

Implementation notes

Use the existing `customers` table, but verify the active column shape. App code expects `full_name`; the oldest migration shows `name`, so the migration/tests must make this explicit.

Production CSS should reuse the repo's existing Maris tokens in `assets/css/style.css` where possible, add custom-order scoped tokens only for alpha variants, include the 768px one-column breakpoint, and keep email card body text at readable contrast.
